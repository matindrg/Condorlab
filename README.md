## درباره‌ی پروژه

**کندرلب (Condorlab)** یک مؤسسه‌ی آموزشی المپیاد زیست در ایران است که آزمون و سنجش، دوره/کلاس و مشاوره ارائه می‌دهد.

هدف محصول دیجیتال: تبدیل تجربه‌ی آزمون از «PDF پراکنده» به یک چرخه‌ی یکپارچه‌ی **خرید ← برگزاری ← کارنامه ← رتبه**، با شرایط واقعی آزمون (پاسخ‌برگ، زمان‌سنج، نمره‌ی منفی) و کارنامه‌ای که نشان دهد ضعف اصلی کجاست.

**فاز فعلی (A):** آزمون رایگان با دامنه‌ی کامل — هر سه نوع سؤال، PDF-only، قفل کامل آزمون، حالت Open، مدیریت نسخه‌دار کلید، کد تخفیف زمان‌دار، کارنامه/رتبه و پنل مدیریت.

### واژه‌نامه‌ی سریع

| اصطلاح | معنا |
|---|---|
| **فاز A / B / C** | رویکرد عرضه‌ی مرحله‌ای: A آزمون رایگان و دامنه‌ی کامل برگزاری، B آزمون پولی + OTP + اشتراک، C مقیاس |

## نمونه‌ی فنی: `session-lock/`

پیاده‌سازی مرجع برای «یک دستگاه فعال + Takeover صریح + Heartbeat + همگام‌سازی پاسخ آفلاین» در آزمون پرریسک.

- **فنی:** Node.js 20+، TypeScript، Express، Redis 7 (`ioredis`)، Zod، JWT
- **کلاینت:** React 18 hook + مدال Takeover دسترس‌پذیر
- **گذر از typecheck و build:** ✅

### اجرا

```bash
cd session-lock
cp .env.example .env          # مقادیر را برای محیط خود جایگزین کنید
docker compose up -d          # Redis 7
npm install
npm run dev                   # http://localhost:3000
```

> مستندات کامل طراحی قفل، اسکیمای Redis، Lua scripts و حالت‌های خطا در [session-lock/README.md](session-lock/README.md).

**⚠️ این نمونه مرجع معماری است، نه سرویس تولیدی:** تلاش‌ها و پاسخ‌های نهایی باید در پایگاه داده‌ی اصلی ذخیره شوند؛ Redis فقط برای هم‌آهنگی قفل و پاسخ‌های کوتاه‌عمر استفاده می‌شود.

## اصول طراحی محصول (خلاصه)

- **شفافیت مالی:** قیمت، مالیات، تخفیف و بازپرداخت در هر گام روشن.
- **عدالت آموزشی:** تغییر کلید پس از انتشار نتایج، بازتصحیح همه و اعلان شفاف دارد.
- **پایداری آزمون:** ذخیره‌ی خودکار، قفل دستگاه، بازیابی پس از قطعی.
- **حداقل داده‌ی شخصی:** بدون نام کاربری، با شناسه‌ی داخلی و ورود ساده.
- **موبایل‌فرست:** طراحی از ۳۲۰px؛ بخش مهمی از کاربران موبایل‌اند.
- **بارگذاری بدون پرش:** اسکلت هم‌ابعاد پیش از محتوا، بدون اسپینر تمام‌صفحه.
- **دسترس‌پذیری:** RTL، کنتراست WCAG AA، کار در موبایل.
