## ۱. نمای کلی معماری فنی (Technical Stack Overview)

```text
[ کلاینت / مرورگر داوطلب و ادمین ]  <=====>  [ Nginx Reverse Proxy + SSL ]
                                                        │
                      ┌─────────────────────────────────┴─────────────────────────────────┐
                      ▼                                                                   ▼
       [ فرانت‌اند: Next.js 15 App Router ]                               [ بک‌اند: NestJS REST API ]
       • React 19 + Tailwind CSS v4                                       • TypeScript + Prisma ORM
       • GSAP ScrollTrigger + Lenis                                       • WebSocket / SSE (مانیتورینگ زنده)
       • Framer Motion (افکت 3D Tilt)                                     • Telegraf / Bot Webhook
                      │                                                                   │
                      └─────────────────────────────────┬─────────────────────────────────┘
                                                        ▼
                                       [ لایه داده، ذخیره‌سازی و کش ]
                                       • PostgreSQL 16 (داده‌های پایدار و لجر)
                                       • Redis 7 (قفل نشست، هارت‌بیت، صفوف)
                                       • S3-Compatible Storage (فایل‌های PDF و رسانه)
```

## ۲. پشته فرانت‌اند و رابط کاربری (Frontend & UI Stack)

| نام فریم‌ورک / کتابخانه | نسخه | حوزه کاربرد در کندرلب | توجیه انتخاب و مزیت فنی |
|---|---|---|---|
| **Next.js (App Router)** | `15.x` | فریم‌ورک اصلی فرانت‌اند (SSR / ISR / CSR) | بهینه‌سازی عالی برای سئو، سرعت بارگذاری اولیه، و یکپارچگی مسیرها |
| **React** | `19.x` | کتابخانه ساخت رابط کاربری | استفاده از React Server Components و هوک‌های مدرن |
| **Tailwind CSS** | `v4.x` | استایل‌دهی یوتیلیتی و سیستم طراحی | موتور جدید و فوق‌العاده سریع بدون نیاز به کانفیگ سنگین |
| **shadcn/ui + Radix UI** | آخرین نسخه | کامپوننت‌های پایه (دیالوگ، تب، مدال، پاپ‌اور) | کدهای در دسترس (Accessible / WAI-ARIA) با کنترل ۱۰۰٪ بر استایل و بدون وابستگی بسته سیاه |
| **Lucide Icons (`lucide-react`)** | نسخه پایدار | آیکون‌های وکتور سیستم | سبک، خوانا و هماهنگ با تایپوگرافی علمی |
| **KaTeX (`katex`)** | `0.16.x` | رندر فرمول‌های ریاضی و بیوشیمیایی | رندر فوق‌سریع سمت سرور فرمول‌ها بدون کاهش LCP |
| **PDF.js (`pdfjs-dist`)** | نسخه پایدار | رندر امن و روان صفحات PDF آزمون | رندر برداری با رزولوشن بالا بدون اتکا به افزونه‌های مرورگر و امکان درج واترمارک شفاف ضدتقلب |

## ۳. پشته انیمیشن، تعاملات اسکرول و افکت سه‌بعدی (Motion & Interactive Stack)

| نام ابزار / لایبرری | نقش در صفحه اصلی و رابط کاربری | مکانیزم اجرایی |
|---|---|---|
| **GSAP (GreenSock)** | مدیریت انیمیشن‌های دقیق زمانی | تایم‌لاین‌های روان بدون افت فریم (۶۰fps) |
| **GSAP ScrollTrigger** | کنترل اسکرول، Pin کردن سکشن‌ها و Scrubbing | پین کردن بخش معرفی اساتید، معرفی گیمیفیکیشن و پیشرفت گام‌به‌گام با اسکرول کاربر |
| **Lenis (`lenis/react`)** | اسکرول نرم و یکنواخت (Smooth Scroll) | هماهنگی فوق‌العاده روی مک و ویندوز بدون تداخل با تاچ اسکرین موبایل |
| **Framer Motion (`framer-motion`)** | مدیریت ژست‌های حرکتی و ترنزیشن‌ها | پیاده‌سازی افکت 3D Tilt کارت‌های آزمون با استفاده از `perspective` و محاسبه مختصات نشانگر موس |

## ۴. پشته بک‌اند و پردازش منطق (Backend & Processing Stack)

| ابزار / پلتفرم | نسخه / نوع | نقش در سیستم |
|---|---|---|
| **NestJS** | `10.x` | فریم‌ورک ماژولار سازمانی با معماری تزریق وابستگی (DI) برای تمام وب‌سرویس‌های آزمون، پرداخت و احراز هویت |
| **TypeScript** | `5.x` | زبان مشترک فرانت‌اند و بک‌اند جهت تضمین Type-Safety در کل پروژه |
| **Prisma ORM** | `5.x` | مدیریت اسکیمای دیتابیس، مایگریشن‌های خودکار و پرس‌وجوهای امن Type-safe بدون ریسک SQL Injection |
| **BullMQ** | `5.x` | مدیریت صف‌های ناهمگام در ردیس برای: بازتصحیح سراسری آزمون، ارسال ایمیل‌های تراکنشی، و انقضای کوپن‌های زمان‌دار |
| **Zod** | `3.x` | اعتبارسنجی دقیق داده‌های ورودی (Validation) در لایه API و فرم‌های کاربری |

## ۵. پایگاه‌داده، ذخیره‌سازی و کش (Database & Cache)

| ابزار | نسخه | وظیفه در پروژه |
|---|---|---|
| **PostgreSQL** | `16.x` | پایگاه‌داده رابطه‌ای اصلی: ذخیره دفترکل تغییرناپذیر مالی (Ledger)، کاربران، سوالات، نسخه‌های آزمون و کارنامه‌ها |
| **Redis** | `7.x` | پایگاه داده درون‌حافظه‌ای: قفل سشن آزمون (Lock/Heartbeat)، کنترل Takeover، صفوف ناهمگام و رزرو اتمیک ظرفیت آزمون |
| **S3-Compatible Storage** | MinIO / ابری | ذخیره‌سازی امن فایل‌های PDF آزمون، پاسخ‌نامه‌های تشریحی، و تصاویر سوالات با تولید لینک‌های امضاشده کوتاه‌عمر (Presigned URLs) |

## ۶. اکوسیستم تلگرام و سرویس‌های بیرونی (Telegram & External Services)

| سرویس / کتابخانه | نوع اتصال | نقش و نحوه پیاده‌سازی |
|---|---|---|
| **Telegraf / Grammy** | Webhook | فریم‌ورک ساخت بات تلگرام برای اطلاع‌رسانی کارنامه، تیکت پشتیبانی و دانلود کتب المپیاد |
| **Cloudflare Workers (Edge)** | Serverless Proxy / Bot Gateway | پروکسی واسط جهت برقراری ارتباط بدون فیلتر بین وب‌هوک تلگرام و سرور اصلی کندرلب در ایران |
| **زرین‌پال (ZarinPal IPG)** | REST API + Sandbox | پردازش پرداخت، رزرو صندلی‌های رسمی و اعمال تخفیف‌های شکاری |
| **سرویس ایمیل تراکنشی** | SMTP / API | ارسال ۵ قالب ایمیل استاندارد (تأیید، رمز، رسید، کارنامه، اصلاح کلید) با پروتکل‌های SPF/DKIM |
