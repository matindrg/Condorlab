## ۰. فلسفه گیمیفیکیشن در کندرلب: «حیثیتی، علمی و عملکردی»

دانش‌آموزان المپیاد زیست (به‌ویژه پایه‌های دهم و یازدهم سمپاد) یکی از باهوش‌ترین و رقابتی‌ترین گروه‌های دانش‌آموزی کشورند. انگیزه‌بخش اصلی این بچه‌ها **غرور علمی (Ego)، اثبات برتری و تشنگی برای سنجش عیار واقعی** است.

### خطوط قرمز گیمیفیکیشن کندرلب:
- ❌ **نه به المان‌های لوس و بچه‌گانه:** گردونه شانس، حیوانات سخنگو یا پاداش‌های فانتزی در این اکوسیستم دافعه دارند.
- ✅ **بله به چالش‌های تحلیلی سنگین:** مسائل عمیق کمپبل، سوالات تحلیلی شبیه مرحله ۲، و نمودارهای شبیه سیستم‌های رنکینگ Codeforces و Chess.com.
- ✅ **تفکیک کامل از آزمون رسمی:** امتیازات و ریتینگ گیمیفیکیشن هرگز نمره‌ی خام یا رتبه‌ی رسمی آزمون را تغییر نمی‌دهند؛ این دو سیستم موازی اما مستقل هستند.

## ۲. چالش روزانه کمپبل و استریک (Daily Campbell Streak)

### ۲٫۱. نحوه عملکرد
1. **انتشار خودکار:** هر روز رأس ساعت ۰۸:۰۰ صبح، یک سؤال استاندارد و مفهومی از یکی از فصول کمپبل در سایت فعال می‌شود.
2. **پنجره زمانی ۲۴ ساعته:** دانش‌آموز تا ساعت ۰۷:۵۹ صبح روز بعد فرصت دارد به سؤال پاسخ دهد.
3. **زمان‌سنج ۵ دقیقه‌ای:** از لحظه کلیک روی «شروع چالش امروز»، یک زمان‌سنج معکوس ۵ دقیقه‌ای آغاز می‌شود تا امکان جستجو در کتاب یا اینترنت به حداقل برسد.
4. **ثبت پاسخ و فیدبک آنی:** بلافاصله پس از ثبت پاسخ، وضعیت (درست/غلط)، پاسخ تشریحی کامل، رفرنس صفحه کتاب کمپبل و آمار درصد پاسخگویی سایر المپیادی‌ها نمایش داده می‌شود.

### ۲٫۲. قوانین استریک (Streak Invariants)
- **افزایش استریک:** پاسخ به سؤال روز (صرف‌نظر از درست یا غلط بودن) شمارنده استریک روزانه را ۱ روز افزایش می‌دهد (هدف: ایجاد عادت روزانه مطالعه).
- **پاداش پاسخ درست:** اگر پاسخ درست باشد، علاوه بر حفظ استریک، امتیاز تجربه (XP) و ریتینگ کاربر افزایش می‌یابد.
- **شکستن استریک:** عدم شرکت در چالش در بازه ۲۴ ساعته باعث صفر شدن شمارنده استریک می‌شود.
- **استریک‌فریز (Streak Freeze):** برای شرایط اضطراری (بیماری یا امتحانات مدرسه)، هر کاربر می‌تواند حداکثر ۱ بار در هر ۳۰ روز از «یخ استریک» استفاده کند تا استریکش از بین نرود.

## ۳. سیستم سطوح و رتبه‌بندی پویا (Olympiad Tiers & Elo Rating)

ریتینگ علمی کاربر با فرمول استاندارد Elo (مشابه سیستم فدراسیون جهانی شطرنج) پس از هر آزمون یا حل سؤالات چالشی بازمحاسبه می‌شود:

$$\Delta R = K \times (S - E)$$

که در آن $K$ ضریب اهمیت سؤال/آزمون، $S$ نتیجه واقعی (۱ برای برد/درست، ۰ برای باخت/غلط) و $E$ احتمال موفقیت موردانتظار بر اساس سختی سؤال است.

### ۳٫۱. جدول سطوح نخبگانی (Official Tiers)

| سطح (Tier) | عنوان فارسی | بازه ریتینگ (Rating) | رنگ / نشان گرافیکی | مفهوم نخبگانی |
| :---: | :--- | :---: | :---: | :--- |
| **۱** | **کاوشگر کمپبل** (Campbell Explorer) | کمتر از ۱۲۰۰ | خاکستری متالیک | شروع مسیر مطالعه رفرنس‌ها |
| **۲** | **پژوهشگر زیست** (Biology Scholar) | ۱۲۰۰ تا ۱۳۹۹ | سبز زمردی | تسلط بر مباحث پایه‌ای و جلد ۱ و ۲ |
| **۳** | **شکارچی مرحله ۱** (Stage 1 Hunter) | ۱۴۰۰ تا ۱۵۹۹ | آبی کبالت | آمادگی کامل برای قبولی مرحله اول |
| **۴** | **مدعی مرحله ۲** (Stage 2 Challenger) | ۱۶۰۰ تا ۱۷۹۹ | بنفش آمتیست | تسلط بر سوالات تحلیلی و گزاره‌ای |
| **۵** | **مدال‌آور کشوری** (National Medalist) | ۱۸۰۰ تا ۱۹۹۹ | طلایی نئونی | در سطح کسب مدال طلای کشوری |

## ۴. نشان‌ها و بج‌های تسلط مبحثی (Domain Mastery Badges)

برای ایجاد انگیزه در تسلط سرفصلی بر بیولوژی، نشان‌های افتخار به پروفایل دانش‌آموز الصاق می‌شوند:

1. **نشان شکارچی ژنتیک (Genetics Virtuoso):** حل ۳۰ تست پیاپی ژنتیک کلاسیک و احتمال با دقت بالای ۸۵٪.
2. **استاد بیوشیمی و انرژی (Biochemistry Master):** تسلط کامل بر فصول فتوسنتز، تنفس سلولی و مسیرهای متابولیک.
3. **نابغه فیزیولوژی (Physiology Elite):** پاسخ بدون غلط به سوالات دستگاه گردش خون، کلیه و اعصاب.
4. **نگهبان استریک ۳۰ روزه (Monthly Phoenix):** حفظ استریک چالش روزانه به مدت ۳۰ روز متوالی.

## ۵. دوئل‌های علمی ۱ به ۱ (1v1 Asynchronous Biology Duels - نقشه فاز B)

برای فاز B سامانه، قابلیت دوئل اضافه می‌شود:
- **مکانیزم:** دو المپیادی وارد یک دوئل ۵ سؤالی می‌شوند.
- **زمان‌بندی نوبتی/هم‌زمان:** هر کاربر در ۳ دقیقه به ۵ تست سرعتی پاسخ می‌دهد.
- **تبادل ریتینگ:** برنده‌ی دوئل ریتینگ حریف را جذب می‌کند و کارنامه مقایسه‌ای دوئل در استوری و تلگرام قابل اشتراک‌گذاری است.

## ۶. مدل داده اختصاصی گیمیفیکیشن

```sql
-- جدول استریک کاربران
CREATE TABLE user_streaks (
    user_id UUID PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
    current_streak INT NOT NULL DEFAULT 0,
    longest_streak INT NOT NULL DEFAULT 0,
    last_completed_date DATE NULL,
    freeze_available INT NOT NULL DEFAULT 1,
    freeze_used_count INT NOT NULL DEFAULT 0,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- جدول سؤالات چالش روزانه
CREATE TABLE daily_challenges (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    challenge_date DATE NOT NULL UNIQUE,
    question_id UUID NOT NULL REFERENCES questions(id),
    rating_weight INT NOT NULL DEFAULT 20,
    total_participants INT NOT NULL DEFAULT 0,
    correct_count INT NOT NULL DEFAULT 0,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- جدول تلاش‌های روزانه کاربران
CREATE TABLE daily_submissions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    challenge_id UUID NOT NULL REFERENCES daily_challenges(id),
    selected_answer JSONB NOT NULL,
    is_correct BOOLEAN NOT NULL,
    time_taken_seconds INT NOT NULL,
    submitted_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    CONSTRAINT uq_user_daily_challenge UNIQUE (user_id, challenge_id)
);

-- جدول ریتینگ و سطوح کاربران
CREATE TABLE user_ratings (
    user_id UUID PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
    current_rating INT NOT NULL DEFAULT 1000,
    peak_rating INT NOT NULL DEFAULT 1000,
    tier VARCHAR(32) NOT NULL DEFAULT 'Campbell_Explorer',
    total_challenges_solved INT NOT NULL DEFAULT 0,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```
